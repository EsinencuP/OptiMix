# Optimix: перенос на React + Next.js

9 ноября 2026. Основание — [ТЗ владельца](OWNER_BRIEF.md) и его прямое подтверждение полного переноса на React + Next.js. Предыдущая опубликованная версия: `03e217fd4670cfa76bf953e04e1e7b8e61c1fe64`.

## Реализовано

Весь сайт перенесён с Astro на Next.js App Router и React: настоящие TSX-компоненты, серверный рендер страниц, клиентские границы для взаимодействий. Astro-шаблоны, зависимости и события удалены. Общие BaseLayout, SiteHeader и SiteFooter сохранены в React. Актуальная архитектура и команды — [PROJECT_GUIDE v4.0](../PROJECT_GUIDE.md).

Сгенерированы 72 локализованных маршрута, по 24 для EN/RO/RU. Канонические адреса всегда начинаются с `/en/`, `/ro/`, `/ru/`; прежние английские URL перенаправляются кодом 308. Языковые переключатели сохраняют страницу, slug и допустимый `?step=`. Обновлены canonical, hreflang и x-default; неизвестные URL возвращают настоящий локализованный HTTP 404. Next дополнительно создаёт два служебных артефакта.

Сохранены графитовая палитра, Roboto, SVG-знак, композиция первого экрана, HTML-интерфейсы и Canvas-графики. Для текста поверх растрового фона hero применены более светлые контекстные оттенки, без изменения основного графита/бирюзы/оливкового. Новые отступы основаны на 8px-шкале.

Services работает на Radix Navigation Menu с hover, кликом, клавиатурой, Escape и закрытием снаружи. На мобильном — accordion внутри native popover. Все шесть направлений имеют страницы, отдельного обзора услуг нет. FAQ содержит пять полных ответов и CTA; четыре крупных шага связаны стрелками и завершаются CTA. Без JS меню, FAQ, шаги и портфолио остаются доступны.

Hero последовательно показывает CRM, People, Processes и Systems, с чтением 3.6 секунды и переходом 0.9 секунды. Motion управляет transform/opacity; поддержаны ручной выбор, пауза, hover/focus, потеря фокуса окна, visibility и reduced motion. Физическая колода портфолио сохранена: слои 1…5 неизменны, hover поднимает карту на 64px, выбранная карта получает слой 10; повторный клик переворачивает её, вложенные ссылки действуют отдельно. Открытие/закрытие карты анимируется через FLIP transform, без анимации размеров. Контроллеры монтируются по маршруту и освобождаются при переходах.

Сохранены все шесть настоящих продуктов, внешние URL и локализованные страницы. По последнему ТЗ два примера под hero и примеры на шести страницах направлений — нейтральные заготовки: название, короткое описание и место для скриншота. Предыдущая привязка направлений к продуктам отменена; заполнение и выбор проектов будут сделаны по README. Уже подтверждённые описания PDF/CRM/ERP в самом каталоге сохранены; Commerce/Founder/Recruiting остаются согласованными заготовками.

Блоки Demo access, реквизиты и декоративная нумерация не возвращены. Блок Results/value отсутствует. Изменение входа во внешние приложения не входит в перенос сайта: статус передачи требования о беспарольном переключении ролей — [DEMO_PLATFORM_HANDOFF.md](../revision-2026-11-09/DEMO_PLATFORM_HANDOFF.md). Для трёх недоступных репозиториев владелец принял документ; формы задач ERP/CRM ранее подготовлены, но задачи пользователем ещё не отправлены.

## Выбранные инструменты

Использованы пять решений по назначению: [Motion](https://motion.dev/docs/react-animation) для новой анимации, [Radix](https://www.radix-ui.com/primitives/docs/components/navigation-menu) для навигации и FAQ, [Lucide](https://lucide.dev/guide/react) для единых новых иконок, нативные [React/Next View Transitions](https://nextjs.org/docs/app/guides/view-transitions) для переходов, существующий GSAP только для сложных схем CRM/ERP. Motion и GSAP не управляют одним компонентом. Magic UI, React Bits и shadcn не добавлялись.

Правила сверены с [GOV.UK spacing](https://design-system.service.gov.uk/styles/spacing/), [Atlassian spacing](https://atlassian.design/foundations/spacing/), [GitHub Primer](https://primer.style/product/primitives/) и [Law of Proximity](https://lawsofux.com/law-of-proximity/). Они применены к отступам, состояниям и группировке, сохраняя утверждённый дизайн Optimix.

## Проверки и доказательства

- `npm run check`, `npm run lint`, `npm run build` проходят. Node 24.x; Next.js 16.4.5, React 19.3.1. `npm run test:site` воспроизводит браузерную проверку production-сборки.
- [qa/results.json](qa/results.json): 72 страницы × 5 ширин (1440, 1024, 768, 390, 320) = 360 состояний. Проверены landmarks, заголовки, изображения, переполнение, метаданные, локализованные ссылки и DOM-контраст не ниже 4.5:1. Ошибки браузера и предупреждения фиксируются в том же файле.
- Проверены 120 внутренних якорей и 24 старых адреса. В [hero-baseline.json](hero-baseline.json) сохранена геометрия Astro-версии: координаты заголовка, описания, CTA и сцены RU при 1440×960 совпали с Next с дельтой 0. Это проверка композиции первого экрана, а не утверждение попиксельного совпадения всего сайта.
- Проверены меню/FAQ с клавиатуры, 30 мобильных состояний лиц/оборотов колоды, точный hover −64px и неизменные слои, FLIP без анимации размеров, вложенные ссылки, скачивание настоящего текстового брифа, CRM/ERP-панели и процессный симулятор с исключением и восстановлением.
- Проверены полный цикл hero, ручная/hover-пауза, мобильная анимация, reduced motion, потеря фокуса окна, повторные клиентские переходы без перезагрузки документа, вызов нативного View Transition, режим без JS и локализованные 404. Во всех 72 HTML отсутствует прежний виджет реквизитов.
- [hero-raster-contrast.json](hero-raster-contrast.json): дополнительная выборка фактического композитного фона под текстом hero для трёх языков и пяти ширин, минимум 4.525:1. Текст временно скрывался без изменения геометрии; фон измерен по сетке 6px внутри текстовых прямоугольников, затем рассчитан контраст исходного цвета. Эта выборка дополняет DOM-проверку и не является полным попиксельным аудитом.
- Скриншоты находятся в [qa/](qa/). `npm audit --omit=dev` — 0 уязвимостей, результат в [runtime-audit.json](runtime-audit.json). Полный audit сообщает 10 moderate в цепочке инструментов ESLint/minimatch; автоматическое принудительное понижение зависимостей не применялось.

Ограничения: Chrome/Playwright на Windows; физические iOS/Android, Safari и ручной screen reader не проверялись. В headless подтверждена потеря фокуса окна с отключённой CDP focus-emulation, но не реальное состояние `document.hidden` фоновой вкладки. bfcache lifecycle реализован, отдельная ручная приёмка bfcache не проводилась. Контраст Canvas-графиков и доступность всех графических элементов этим DOM-тестом не сертифицированы. Старые ограничения и единичный dev-time ViewTransition timeout остаются историей в design-qa.md.

## Запуск и публикация

Локальный production preview: **http://127.0.0.1:4322/ru/**. После клонирования: `npm ci`, `npm run check`, `npm run build`, `npm start`; разработка — `npm run dev` на том же порту.

`vercel.json` явно задаёт Next.js, `npm run build` и `.next`, перекрывая прежние настройки Astro в проекте Vercel согласно [документации конфигурации](https://vercel.com/docs/project-configuration/vercel-json). Production: **https://opti-mix-three.vercel.app/ru/**. Факт push и результат проверки deployment для точного коммита сообщаются отдельно после публикации; этот отчёт сам по себе не подтверждает завершение deployment.
