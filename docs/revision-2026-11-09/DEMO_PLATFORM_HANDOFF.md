# Требование к внешним демо-платформам

Источник: пункт 1 `OWNER_BRIEF.md`, 9 ноября 2026. Это передача требования для отдельных приложений, а не заявление об изменении их авторизации.

Посетитель открывает публичную учебную среду без ввода учётных данных. Если в продукте есть несколько ролей/пользователей, переключатель расположен внутри приложения; текущая роль явно показана. Переключение меняет интерфейс и доступные действия в соответствии с выбранной учебной ролью. Используются только изолированные синтетические данные. Рабочая авторизация production не отключается.

Проверить прямой переход, перезагрузку, выбор всех учебных ролей, мобильный/десктопный интерфейс и возможность сброса демо. Обновить README публичным URL и инструкцией выбора ролей; логины и пароли посетителю не нужны. Личные ChatGPT-аккаунты не используются как общий вход в демо.
