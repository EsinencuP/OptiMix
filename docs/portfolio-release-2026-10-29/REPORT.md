Все страницы и каталог доступны на RU/EN/RO. Пункт «Портфолио» в шапке и подвале ведёт в каталог. На страницах продукта есть предыдущий/следующий проект и возврат ко всем продуктам. Сохранены прежние маршруты процессов, якоря главной, графитовая палитра, Roboto и механика колоды. Старые демонстрационные названия больше не определяют состав актуального портфолио.

## Где редактировать дальше

`src/content/portfolio-catalog.ts` — основной источник шести продуктов: имена, URL, категории, описание, теги, особенности и признак `draft`. Для Commerce/Founder/Recruiting сейчас намеренно нет придуманных функций или вымышленных интерфейсных сцен. После обновления README можно заполнить содержание и снять `draft` без изменения маршрутов или галереи.

`CatalogProjectPage.astro` — шаблон новых страниц; `PortfolioIndexPage.astro` — каталог; `CatalogVisual.astro` — реальные снимки и нейтральные обложки; `CatalogRelated.astro` — навигация между продуктами. Тексты подробных CRM/ERP-страниц остаются в `portfolio-pages.ts`, внешние ссылки они берут из общего каталога.

Снимки AI PDF Editor и Evo ERP получены из работающих приложений. PDF открыт на встроенном синтетическом примере; ERP — в публичном учебном пространстве. Числа на снимке ERP являются данными учебного приложения, а не доказательством результатов клиента. Обложки остальных продуктов — графическое оформление, не снимки их интерфейса. Код других продуктов не копировался, новые зависимости не добавлялись.

- Проверены 30 внутренних маршрутов и 63 якорные ссылки, canonical/hreflang и сохранение текущего продукта при смене языка.

## Что остаётся перед полным публичным релизом

1. Владелец добавит README для Commerce, Founder и Recruiting; после этого можно наполнить их заготовки.
2. Владелец отдельно настроит публичный доступ к трём демо на ChatGPT Sites. Сейчас они возвращают вход/401; права доступа не изменялись. Их GitHub URL сохранены точно по запросу, хотя текущему подключению репозитории возвращают 404.
3. CRM открывает страницу входа; попытка войти опубликованными учебными реквизитами вернула «Unable to sign in». Работоспособность её авторизации требует отдельной проверки владельцем. Evo ERP удалось открыть опубликованной учебной учётной записью. Это внешние приложения; их backend не менялся.
4. AI PDF Editor доступен, ручное открытие встроенного PDF подтверждено. Облачный AI на внешнем сайте имеет отдельный режим owner testing; его публичный доступ и обработка реальных документов здесь не проверялись.
5. `noindex, nofollow` сохранён по действующим правилам проекта. Снятие запрета индексации и production-публикация — отдельный этап.

Физические touch-устройства, Safari, ручной screen reader и production Lighthouse не проверялись. Проверка контраста оценивает CSS-фоны/DOM-текст, не пиксели скриншотов и Canvas. Исторические ограничения ViewTransition и прежних проверок остаются в design-qa.md.

Локальный сервер оставлен запущенным на `127.0.0.1:4322`; это актуальная статическая сборка. Для повторного просмотра после правок выполните сборку и запустите `python -m http.server 4322 --bind 127.0.0.1 --directory dist` либо Astro preview. Публикация и внешние права доступа в этой задаче не менялись.
