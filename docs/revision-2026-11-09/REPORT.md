## Передача и границы

Владелец согласовал документ передачи для Commerce/Founder/Recruiting вместо недоступных репозиториев. Коннектор GitHub подготовил две формы задач ERP/CRM, но вернул `awaiting_user_submission`; задачи **не созданы**, URL/номера не выдуманы. Точное состояние и критерии приёмки находятся в `DEMO_PLATFORM_HANDOFF.md`. Авторизация внешних приложений этой итерацией не менялась; сайт не обещает уже работающий вход без пароля.

Новых зависимостей нет. Публикация через Git проверяется после push отдельно от локальной приёмки этого отчёта. Noindex сохранён. Физические iOS/Android, Safari и ручной screen reader не проверены; событие скрытия вкладки и bfcache предусмотрены в коде, но отдельный браузерный тест для них не заявлен. Предыдущее единичное наблюдение dev ViewTransition timeout остаётся в историческом QA; в текущих проверках не повторилось.

PROJECT_GUIDE обновлён до v3.14, DESIGN_DOCUMENT — раздел 32, AGENTS содержит новое правило вместо прежней публикации реквизитов. Старый verify-demo-access удалён; проверку удаления заменяет verify-package1. Исторические отчёты и снимки оставлены для трассировки решений.
