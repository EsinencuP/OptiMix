# Смена палитры Optimix — 29 октября 2026

Сайт переведён в графитовую палитру с бирюзовыми акцентами по двум изображениям владельца. Применение охватывает все 39 страниц RU/EN/RO: главную, CRM/ERP, пять модулей, проект, интерактивное демо, бриф, конфиденциальность и 404.

Кнопки и мелкие подписи используют близкие к референсу оттенки для читаемости. Фон первого экрана сохраняет ленты и орбиту; локальные исходные PNG перекрашиваются средствами CSS, без перезаписи. На экранах до 960px остаётся вариант без орбиты. Передние CRM/Analytics-панели остаются светлыми HTML-компонентами, Canvas-графики получили бирюзово-оливковую гамму. Знак бренда переведён в локальный SVG без белой подложки, зелёные SVG-иконки перекрашены в бирюзу.

Сохранены текущая композиция, локальный Roboto, тексты, маршруты, якоря, три языка и все шесть карточек. Колода сохраняет слои 1…5, подъём на 64px без изменения угла/масштаба/слоя, слой 10 после выбора и повторный клик для переворота.

Исходные изображения: [первый экран](reference-hero.jpg), [направления](reference-services.jpg). Финальные браузерные снимки: [главная 1440px](verified/ru-home-1440.png), [главная 390px](verified/ru-home-390.png), [направления](verified/services-1440.png), [CRM](verified/crm-confirmed-1440.png), [ERP](verified/ru-portfolio-erp-1440.png), [бриф](verified/ru-contact-1440.png). ## Проверки

Результаты и точные параметры записаны в [verified/results.json](verified/results.json); сценарий — `experiments/verify-palette.mjs`.

Итог основного прогона: 90 сочетаний, без переполнения, отсутствующих изображений, браузерных ошибок и замечаний автоматической проверки контраста DOM-текста. Каталог `verified/` содержит результаты приёмки; снимки вне него и `final-qa/` — промежуточные итерации.

- 39 страниц при 1440 и 390px, плюс главные трёх языков при 320/768/1024/1280px: 90 сочетаний.
- Проверены отсутствие горизонтального переполнения и потерянных изображений, язык и основные landmarks.
- Проверены открытие, переворот и переход из ERP-карты, постоянные слои, hover на 64px, мобильный выбор карты, меню/Escape, FAQ, смена языка через Astro.
- Проверены демо: остановка, рассмотрение, завершение, сброс; бриф: ввод и скачивание текстового черновика.
- Выполнены проверка контраста DOM-текста и отдельный проход с `prefers-reduced-motion: reduce`.
- Дополнительно проверены SVG-номера CRM на RU/EN/RO при 1440 и 390px: белый активный номер на `#4B7C74`, неактивные `#5A6570` на белом. В обычном motion-режиме проверены пауза/выбор шага CRM и пауза/раскрытие модуля ERP; [CRM](verified/crm-workflow-confirmed.png), [ERP](verified/erp-hub-confirmed.png).
- Astro build: 39 страниц; Astro check: 87 файлов, 0 ошибок/предупреждений/hints; ESLint, TypeScript и `git diff --check`.

Контрастная проверка — собственный автоматический проход по CSS-цветам и фонам; он не заменяет полный WCAG-аудит и не оценивает пиксели растра/Canvas. Физические телефоны, Safari и ручной screen reader не проверялись. Старые Lighthouse-цифры относятся к предыдущей версии. Изолированное историческое наблюдение ViewTransition остаётся в прежнем отчёте.

При первом dev-проходе одновременная сборка вызвала временные Vite 504 для кеша MotionPathPlugin. Финальная проверка выполняется на статической production-сборке. Недостающих ресурсов, шрифтов или сервисов, блокирующих смену палитры, нет. Новые зависимости не устанавливались.

## Просмотр локально

**[Открыть русскую главную](http://127.0.0.1:4322/ru/)**. Также доступны [CRM](http://127.0.0.1:4322/ru/portfolio/crm/), [ERP](http://127.0.0.1:4322/ru/portfolio/erp/) и [бриф](http://127.0.0.1:4322/ru/contact/).

Сервер статической сборки оставлен запущенным в скрытом процессе на loopback-адресе. PID и журналы находятся в игнорируемой папке `.astro/palette-preview.*`. При необходимости повторного запуска из корня проекта: `npm run build`, затем `python -m http.server 4322 --bind 127.0.0.1 --directory dist` (или `npm run preview -- --port 4322`).
